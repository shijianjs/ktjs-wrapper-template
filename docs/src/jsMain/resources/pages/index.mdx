# ktjs-wrapper-template

A Kotlin/JS wrapper project that already works: one published module wrapping
[`@vaadin/button`](https://www.npmjs.com/package/@vaadin/button), a demo page, this documentation
site, and the tests and release pipeline around them. Copy the repository and rename it — that is the
whole setup, because nothing here is a placeholder waiting to be filled in.

- [Introduction](intro) — what is in it and why it runs as-is.
- [Getting started](guide/getting-started) — build, test, dev servers.
- [Deriving a project](guide/deriving-a-project) — the rename checklist.
- [Live demo](https://shijianjs.github.io/ktjs-wrapper-template/demo/) — the page the `demo` module
  builds.
- [API reference](https://shijianjs.github.io/ktjs-wrapper-template/api/) — Dokka output for the
  published modules.
