<ktjs-features section-title="Why start here" tinted>

<ktjs-feature icon="lucide:play" title="It runs as it is">Cloning it gives you a project that builds, tests and deploys — no placeholder to fill in, no script to run before the first `./gradlew build`.</ktjs-feature>

<ktjs-feature icon="lucide:package" title="One module per package">A wrapper module maps one npm package to one Kotlin package. Adding the second package means copying one directory, not inventing a layout.</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="Types, not dynamic">Upstream `.d.ts` files become `external` declarations checked at compile time; `kotlin-browser`'s `web.*` types keep the surface composable.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in a browser">The module's tests run in Chromium against the real custom element, and the demo has its own Playwright suite — both wired into CI.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs are Kotlin too">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration and sidebars, Markdown pages, English and Chinese.</ktjs-feature>

<ktjs-feature icon="lucide:rocket" title="Pages and release wired">`pagesSite` assembles the documentation, the demo and the API reference; `release.yml` signs and publishes the modules through the Maven Central hub.</ktjs-feature>

</ktjs-features>
