# ktjs-wrapper-template

一个立刻能跑的 Kotlin/JS wrapper 项目：一个发布模块包装
[`@vaadin/button`](https://www.npmjs.com/package/@vaadin/button)，加上 demo 页面、这个文档站，以及围绕
它们的测试与发布流水线。复制仓库、改名即可——这里没有等着被替换的占位符，所以「配置」这一步就是改名。

- [简介](intro)：里面有什么，为什么它直接能跑。
- [快速开始](guide/getting-started)：构建、测试、开发服务器。
- [派生新项目](guide/deriving-a-project)：改名的清单。
- [在线演示](https://shijianjs.github.io/ktjs-wrapper-template/demo/)：`demo` 模块构建的页面。
- [API 文档](https://shijianjs.github.io/ktjs-wrapper-template/api/)：发布模块的 Dokka 产物。
